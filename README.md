# 🎬 AniScraper (本地动漫元数据刮削器)

![License](https://img.shields.io/badge/License-MIT-orange)
![Release](https://img.shields.io/badge/Release-v1.0-brightgreen)

AniScraper 是一款专注于**日本动画**本地元数据（NFO）生成与管理的轻量级桌面工具。

本项目并非旨在替代 tinyMediaManager (TMM) 或 Plex/Emby 内置的全自动刮削器，而是针对一套**极其垂直且严苛的工作流**提供解决方案：在绝对不修改原始文件的前提下，为复杂的本地动漫大合集建立清晰的逻辑结构。

## 🎯 核心痛点与适用人群

本工具专为以下垂类用户（尤其是 PT 保种玩家和自建 NAS 爱好者）设计：

* **PT 硬盘仓鼠**：由于做种限制，**绝对不能**重命名、移动或修改原始视频文件。同时不考虑软链接、硬链接等方案。
* **复杂目录受害者**：常年下载 BDRip 大合集，文件深埋在 `TV/`、`SP/`、`Movie/` 等多级嵌套子文件夹中，传统刮削器经常“迷路”。
* **逻辑结构洁癖者**：不信任纯正则匹配的“盲盒”准确率，需要“所见即所得”的手动干预确认，希望物理硬盘的确凿证据优先级高于网络模糊匹配。

如果你只是想全自动一键刮削常规命名的欧美美剧或电影，**本工具并不适合你**。

## 🤖 关于 AI 辅助开发的声明 (AI-Assisted Project)

**透明度声明：** 本项目从需求解构、架构设计到 UI 逻辑梳理均由个人开发者（主理人）主导，但**底层的核心代码、多线程容错机制以及正则匹配算法，均重度依赖了大型语言模型（LLM）的生成与重构支持。**

这意味着：
1. 代码风格可能存在因 AI 迭代而产生的拼接痕迹。
2. 某些极端边缘情况（Edge Cases）可能尚未被完全覆盖。
如果你在阅读源码或使用过程中发现了不符合常规工程直觉的 Bug，欢迎随时提交 Issue 或 PR 协助修正。

## 🚀 快速上手

1. 前往 [Releases](https://github.com/wen619370-ctrl/AniScraper/releases) 页面下载最新版本的 `AniScraper.exe`（单文件独立运行版，无需配置 Python 环境）。
2. 双击运行，在顶部菜单栏点击 `文件 -> 添加媒体库`，挂载你的本地动漫资源根目录。
3. 在左侧面板选择需要处理的文件夹，系统将自动穿透扫描并列出有效视频。
4. 在顶部核对 Bangumi 搜索结果后，点击执行。系统将在底部日志面板实时反馈 NFO 生成状态。

*(建议：首次使用时，请先使用一个几十 MB 的测试文件夹熟悉“局部勾选执行”与“零碎文件软隐藏”的交互逻辑。)*
